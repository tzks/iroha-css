Recipes

Practical page patterns for AI-built interfaces

Use these recipes as high-quality starting points before inventing custom structure.

Prompt data
Admin

Operational Dashboard

Use `wa-app-shell`, `wa-side-nav`, `wa-page-header`, KPI cards, charts, and table surfaces. 

<main class="wa-app-shell" data-wa-theme="sumi" data-wa-density="compact">
  <nav class="wa-side-nav">...</nav>
  <section class="wa-app-shell__main wa-stack wa-p-4">
    <header class="wa-page-header">...</header>
    <div class="wa-grid">
      <article class="wa-kpi-card">...</article>
      <div class="wa-gauge">...</div>
    </div>
  </section>
</main>
Settings

Settings Page

Use `wa-settings-section`, native controls, visible labels, and compact action bars. 

<section class="wa-settings-section">
  <div><h2>Notifications</h2><p class="wa-text-muted">Delivery preferences.</p></div>
  <form class="wa-form">
    <label class="wa-switch"><input type="checkbox" /> Enable LINE notices</label>
    <div class="wa-action-bar">...</div>
  </form>
</section>
Search

Filterable Data Screen

Use filters above the table, not buried in a modal.

<div class="wa-filter-bar">
  <label class="wa-search"><input class="wa-input" placeholder="Search" /></label>
  <div class="wa-segmented-control">...</div>
</div>
<div class="wa-table-wrap">
  <table class="wa-table wa-table--striped">...</table>
</div>
