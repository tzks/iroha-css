# iroha-css rules

- Use existing `wa-*` classes only.
- Use `data-wa-theme` for theme selection.
- Use `data-wa-density` and `data-wa-contrast` for page-level tuning.
- Do not invent raw color values, token names, or `wa-*` classes.
- Prefer semantic tokens and component tokens.
- Prefer layout primitives before custom CSS.
- Read `docs/ai/class-decision-tree.md`, `docs/ai/component-snippets.md`, and `docs/mcp/classes.manifest.json` before building UI.
- Avoid generic AI-looking SaaS layouts.
- Use app JavaScript for tabs, modals, dropdowns, and toasts behavior.
