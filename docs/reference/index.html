CSS API reference

iroha-css is strongest when AI and humans can rely on stable semantic classes, role tokens, and page-level controls.

Install and import

npm install iroha-css

@use "iroha-css";

<link rel="stylesheet" href="./dist/iroha.css" />

<button class="wa-button wa-button--seal">Publish</button>

Card API

Cards use a top rule and paper-like surface. Use variants sparingly.

<article class="wa-card wa-card--washi wa-flow">
  <h2>Quiet article</h2>
  <p>Layered paper surface and semantic spacing.</p>
</article>
wa-card--quiet wa-card--bordered wa-card--elevated wa-card--washi wa-card--accent

Form API

<label class="wa-field wa-field--invalid">
  Email
  <input class="wa-input" type="email" aria-invalid="true" />
  <span class="wa-error">Enter a valid email.</span>
</label>

Use real labels, `aria-invalid`, and error text. Do not rely on color alone.

Table API

<div class="wa-table-wrap">
  <table class="wa-table wa-table--striped wa-table--compact">...</table>
</div>

Tabs API

<div class="wa-tabs">
  <div class="wa-tabs__list" role="tablist">
    <button class="wa-tabs__tab" aria-selected="true">Tokens</button>
  </div>
  <div class="wa-tabs__panel">...</div>
</div>

CSS provides the surface. Add JavaScript only for actual tab switching behavior.

Charts API

<div class="wa-donut wa-donut--accent" style="--wa-donut-value: 72%">
  <span class="wa-donut__value">72%</span>
</div>

<div class="wa-progress wa-progress--lg">
  <div class="wa-progress__bar" style="--wa-progress-value: 64%"></div>
</div>

Overlay surfaces

Modal, dropdown, and toast styles are CSS-only surfaces. Add behavior in your app layer.

<div class="wa-modal">
  <h2>Confirm</h2>
  <p>Use app JavaScript for focus trap and close behavior.</p>
</div>
