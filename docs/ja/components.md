# コンポーネント

CSS only のコンポーネントを提供します。button、card、hero、nav、form、badge、alert、article、footer、table、tabs、timeline、quote、stat、media、divider、list、callout、avatar、progress、donut chart、bar chart、meter、skeleton、pagination、breadcrumb、dropdown surface、modal surface、toast、accordion、stepper、empty state、chip を含みます。

和風の補助クラスとして、和紙風の面、判子風マーク、家紋風マーク、重ねの影、縦組みテキストも含みます。
