# Claude Code Guide for iroha-css

Use semantic `wa-*` classes and existing tokens. Do not invent new theme names, color variables, or component classes unless the source SCSS and docs are updated together.

Avoid:

- Centered gradient hero sections.
- Repeated rounded cards without hierarchy.
- Raw hex colors in components.
- Decorative effects that hide content.

Prefer asymmetry, quiet spacing, readable contrast, and role-based CSS custom properties.
